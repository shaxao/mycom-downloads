# MyCom 剧本工作流

面向 AI 短剧创作的 Windows 桌面软件，连接剧本、人物场景道具、分镜、素材引用与视频生成。

- 官网与使用指南：https://mycom-official-website.vercel.app
- 下载客户端：请打开本仓库的 **Releases** 页面，下载对应版本的完整绿色版 ZIP。
- 此仓库用于发布完整客户端和更新说明，不提供项目源码。

## 安装与启动

1. 下载 Release 附件中的 `MyCom-Portable-v版本号-win-x64.zip`。
2. 完整解压到固定目录，再运行 `MyCom 剧本工作流.exe`，不要直接在压缩包中运行。
3. 根据界面提示完成软件授权，选择可用模型渠道。
4. 使用剧梦相关功能时，需要自己的剧梦账号；模型额度和剧梦积分分别管理。

每个版本附有 `SHA256SUMS.txt`，可用于核对下载文件。首次安装需要完整 ZIP，单独的 `app.asar` 更新文件不是完整客户端。

## 更新与数据

已有用户优先使用软件内的更新功能。更新前保存工作流并备份用户数据，不要删除 `%APPDATA%\MyCom 剧本工作流\data`。

软件使用及素材生成能力以对应版本和所选服务为准。软件授权、模型调用与剧梦生成可能产生各自的费用。
